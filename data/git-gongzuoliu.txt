Git 工作流基础
Git 是一个分布式版本控制系统，每个开发者都拥有完整的仓库副本。

克隆与分支
使用 git clone 可以把远程仓库复制到本地。git branch 查看分支，git checkout -b 创建并切换到新分支。

提交与合并
git add 把改动加入暂存区，git commit 提交，git merge 把分支合并回主分支。提交信息应当清晰说明改动目的。

解决冲突
当两个人改了同一处，合并会产生冲突，需要手动编辑标记 <<<<<<< 和 >>>>>>> 之间的内容后再提交。

Pull Request 流程
在 GitHub 上通常通过 Pull Request 发起合并请求，由维护者评审后再合并，这是一种代码评审机制。
