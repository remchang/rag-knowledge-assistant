# Docker 与容器

## 容器是什么
容器是把应用及其依赖打包在一起的轻量隔离单元，共享宿主机内核，因此比虚拟机更省资源。容器镜像包含了运行所需的一切。

## 镜像与容器
镜像（image）是只读模板，容器（container）是镜像的运行实例。用 docker run 可以从镜像启动一个容器。

## 常用命令
docker build 根据 Dockerfile 构建镜像；docker ps 查看运行中的容器；docker rm 删除容器。Dockerfile 里的每条指令都会生成一个镜像层。

## 数据持久化
容器停止后内部数据会丢失，需要用卷（volume）或绑定挂载把数据保存到宿主机。卷由 Docker 管理，适合数据库这类有状态服务。
